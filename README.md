# KPMG Data Analysis using Excel
## Project Overview

This project analyzes customer demographics, transactions, and new customer data using Microsoft Excel. The goal is to generate insights into customer behavior, identify high-value customers, and support data-driven business decisions.

## Objective
- Perform data cleaning and preparation
- Segment customers based on demographic attributes
- Analyze transaction patterns and sales trends
- Evaluate new customer potential
- Calculate Customer Lifetime Value (CLV)
- Provide business recommendations
## Datasets Used
1. Customer Address Dataset
- Contains customer location details
- Includes property valuation
2. Customer Demographic Dataset
- Customer personal details
- Job and industry information
- Wealth segment and purchase behavior
3. Transactions Dataset
- Transaction details
- Product information and pricing
- Transaction dates
4. New Customer Dataset
- Potential customer details
- Estimated customer value
## Data Cleaning
- Removed duplicate records
- Handled missing values
- Standardized gender and state formats
- Corrected invalid and inconsistent entries
## Customer Segmentation
- Segmented customers based on:
- Wealth Segment
- Gender
- Job Industry
- Identified key customer groups contributing to business performance
## Transaction Analysis
- Analyzed monthly sales trends
- Evaluated product performance by brand and category
- Identified top customers based on total transaction value
- Calculated average purchase behavior
## New Customer Insights
- Analyzed distribution of new customers across industries
- Studied relationship between property valuation and wealth segment
- Estimated potential revenue from new customers
## Customer Lifetime Value (CLV)
Formula used:
CLV = Average Purchase Value × Purchase Frequency × Customer Lifespan
Where:
- Average Purchase Value = Total Revenue / Number of Purchases
- Purchase Frequency = Total Transactions / Total Customers
- Customer Lifespan = Tenure
Used CLV to identify high-value customers
## Key Insights
- Mass Customers form the largest customer base
- High Net Worth customers generate higher value
- Financial Services, Manufacturing, and Health industries show strong performance
- Customer behavior varies across segments
## Recommendations
- Focus marketing on high-value customers
- Create targeted campaigns for each segment
- Invest in high-performing industries
- Improve strategies for low-performing segments
